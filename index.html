THEARCHITECT_MAX is an independently built software venture portfolio created by Harm Booij. Development began in October 2025 with a clear objective: build a broad set of proprietary software assets, mature each through its own roadmap, and connect the strongest ventures through a common commercial Hub.

The portfolio spans AI systems, engineering intelligence, simulation, infrastructure, evidence systems, media, commerce technology and specialist R&D. Each venture is developed independently, with its own maturity, acquisition reference and commercialization path.
