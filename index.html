Engagement path

Commercial fit first. Confidential technical diligence second.

A serious counterparty does not need unrestricted repository access to start. The first step is to identify an asset or cluster and define the transaction interest.

01

Select the perimeter

Name the asset, thematic cluster or portfolio scope being considered.

02

State the transaction interest

Acquisition, exclusive licensing, non-exclusive licensing, technology transfer or strategic integration.

03

Establish confidentiality

Agree the counterparty, scope and confidentiality framework before source-level or sensitive technical disclosure.

04

Run diligence & negotiate

Review provenance, dependencies, rights, test evidence, build/deployment material and definitive transaction terms.
