Five-lens economic model

Each project is evaluated independently.

The model exposes uncertainty rather than hiding it inside one portfolio multiplier.

Replacement Cost

Current cost-based recreation baseline.

Market / Comparable

Low-confidence marketability proxy until verified comparable transactions are available.

Income / Licensing

Low-confidence monetization proxy until buyer-specific forecasts or royalty benchmarks are available.

Probability-adjusted Strategic Value

Technical completion, commercialization probability, time/risk, rights reserve and buyer-context factors are applied per asset.

Portfolio rule

One project = one standalone IP asset.

Related projects may share a classification family, market context or thematic domain. That relationship does not convert them into one product, one valuation or one transaction unit.

01

Independent identity

Each asset retains its own name, TA-IP identifier, project description and commercial record.

02

Independent value

Each asset has its own seller ask, replacement-cost reference and asset-level economic valuation record.

03

Independent diligence

Ownership, provenance, dependencies, evidence, maturity and transferability are evaluated separately for each asset.

04

Independent transaction

An asset can be acquired or licensed on its own. Multiple assets can be negotiated together only if each included asset is explicitly identified.

Classification families

Related subject matter, separate IP ownership units.

A family helps a buyer discover adjacent assets. It is not itself an IP asset, has no separate asking price, and does not imply that its members must be sold, licensed or transferred together.
