# Controlled Virtual Data Room — Index

Public GitHub Pages remains an informational showroom. Confidential or transaction-specific material is not placed in the public site.

Recommended controlled diligence structure:

1. **01 Ownership** — chain-of-title support, contributor/assignment evidence where applicable, repository licence and rights register.
2. **02 Source & Architecture** — frozen baseline, source manifest, architecture and build documentation.
3. **03 SBOM & Licences** — SBOM, dependency manifests, third-party notices, licensing-obligations report.
4. **04 Security** — security architecture, threat model, dependency-vulnerability evidence, incident/open-risk register.
5. **05 Validation** — tests, qualification records, benchmark evidence, retained hashes and acceptance records.
6. **06 Valuation** — current seller ask, economic methodology, valuation evidence and milestone-conditioned references.
7. **07 Commercial** — transaction perimeter, proposed licence/acquisition structures, exclusions and buyer questions.
8. **08 Transfer Package** — delivery manifest, build/release instructions, configuration, acceptance procedure and handover material.

A transaction-specific data room should be created only for a qualified counterparty and should use a frozen read-only repository snapshot plus cryptographic hashes.
