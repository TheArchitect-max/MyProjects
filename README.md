# THEARCHITECT_MAX — Technology & IP Portfolio

Public commercial catalogue for independently scoped proprietary technology and software assets.

The website presents 83 individually priced assets with seller-side acquisition references, commercial-stage classifications, public-purpose summaries, valuation lenses and transaction boundaries.

## Publication boundary

This repository contains public commercial information only. Detailed technical, legal and transaction material is provided separately through controlled asset-specific diligence.

## Valuation boundary

Seller asks are acquisition positions and remain separate from supporting replacement-cost, market/comparable, income/licensing and probability-adjusted strategic-value lenses. Analytical references are preliminary seller-side estimates, not certified independent market valuations.

EUR amounts are authoritative. USD amounts are indicative conversions and display the exchange-rate date used by the public site.
