The current public assessment is grounded in reviewed repository documentation and an audit of the previous financial model. Evidence strength is stated separately from development activity.

Evidence levels.

Documented capability

80 projects have current documentation reviewed at a checked default-branch snapshot. Documentation describes the claimed implementation and limitations; it does not prove all claims.

Repository-reported tests

Reported checks can be bounded to a version, environment and task. This website does not represent them as independently rerun or as proof of production, scientific or regulatory readiness.

Independent application evidence

Task-appropriate external evaluation, device measurements, user outcomes or other representative evidence must support the buyer's intended use.

Commercial and monetary evidence

Verified cost inputs, comparable rights, cash flows and transfer scope are required for a defensible monetary conclusion. These are not established by this documentation review.

External context has a limited role.

The previous site cited 13 large-company transaction examples across broad sectors. No project-specific comparability adjustments were established, so those examples are not used as valuation inputs in this re-evaluation. Their earlier records remain historical source material; transaction prices and ratios have not been reverified for this release.

The currently checked methodological reference is WIPO’s IP valuation guidance, reviewed on 12 September 2026. It supports method selection and information requirements only.
